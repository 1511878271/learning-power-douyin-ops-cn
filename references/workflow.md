## 1. 产品与用户证据表

| 字段 | 要回答的问题 |
|---|---|
| 产品 | 服务形式、交付、周期、价格区间、使用门槛是什么？ |
| 对象 | 面向哪个年龄、年级、家庭角色和学习情境？ |
| 问题 | 用户能观察到的具体表现是什么？ |
| 机制 | 产品通过什么过程产生帮助？ |
| 证据 | 哪些资料、案例、资质或研究支持该主张？ |
| 边界 | 不适合谁？哪些结果不能保证？ |
| 场景 | 家长在什么时刻最容易意识到问题？ |
| 转化 | 用户看完内容后的合理下一步是什么？ |

输出每条洞察时标注：

- 原始证据：材料中的原话、字段或链接。
- 观察：证据直接显示什么。
- 推断：基于哪些观察形成。
- 待验证：要从搜索、评论或数据中确认什么。

## 2. 搜索词与对标筛选

### 搜索词分组

- 症状：磨蹭、听懂但不会做、粗心、不会审题等。
- 场景：写作业、考试、预习、复习、亲子沟通等。
- 阶段：幼小衔接、小学低年级、升学过渡等。
- 能力：理解力、专注、记忆、迁移、规划等。
- 方法：测评、训练、习惯培养、错题复盘等。
- 误区：补课无效、只刷题、只看分数等。
- 产品：学习力测评、家庭教育咨询、成长方案等。

### 候选词验证表

记录搜索词、访问日期、近期相关内容、代表链接、目标家长评论迹象、内容形式、是否保留。不要仅用总点赞量判断。

### 对标样本表

每个账号至少抽取若干条同主题内容，记录标题、日期、可见指标、开头、结构、镜头、行动号召、代表评论和链接。样本不足时写明限制，不生成精确内容比例。

### 标题评审

### 口播卡


## 5. 发布检查

### 必须改

- 标题、封面与内容承诺不一致。
- 虚构案例、指标、资质或对标数据。
- 把学习困难单因归结为产品可解决的问题。
- 暴露未成年人身份、成绩或家庭隐私。
- 包含绝对化效果、保证性承诺或未经核验的平台禁限表达。

### 建议改

- 开头铺垫过长。
- 判断方法不具体。
- 案例没有来源或适用条件。
- 互动动作不自然或超过一个。
- 屏幕文字过密、提词感强、镜头缺少变化。

### 发布前记录

记录版本、发布时间、标题、封面、时长、主题、内容类型、唯一变量和预期指标，便于复盘。
